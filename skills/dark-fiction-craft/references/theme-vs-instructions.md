# Theme versus instructions

| Allowed at full depth | Kept impressionistic |
|---|---|
| A poisoner's calm, the victim's confusion, the investigation | Exact substance, dose and delivery method |
| A hacker's obsession, the thrill, the fallout | Working exploit code or real targets |
| Battlefield terror, moral injury, atrocity and its cost | Build details for weapons or explosives |
| An addict's cravings, relapse and damage to family | Synthesis steps or sourcing |
| A cult leader's persuasion and the member's slow capture | Nothing needed: this is character work |

Test: lift the passage out of the story. If a reader could follow it as a procedure, make it impressionistic. If it only carries mood, character and stakes, write it fully.
