# Lab boundaries

General patterns, not legal advice. Laws differ by country.

| Situation | Treatment |
|---|---|
| Old single-player game, user owns a copy, wants a feature mod | Help fully |
| Old app that no longer runs on modern OS, user wants a compatibility patch | Help fully |
| Reverse engineering file formats or network protocol of a dead title | Help fully, for private use |
| Rebuilding a shut-down game server for local or LAN play | Help, for private use |
| Sharing a patch that contains none of the original files | Fine to help write; mention the user must not bundle publisher files |
| Uploading the full game or cracked copy for others | Out of scope |
| Game still sold or still has live servers | Not a lab; apply normal rules and avoid abusing the live service |
| Cheating tools for live online play against other people | Out of scope |
| Removing protection to obtain a copy the user never owned | Out of scope |
| Anything touching malware or the Hard Limits | Out of scope |

Quick status check when a search tool is available: is the title for sale on a major store, does the publisher still run servers, has it been re-released? If yes to any, it is not discontinued.
